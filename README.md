
# Kerala Road Safety Intelligence Dashboard (2023–2025)

## Project Overview
An interactive Power BI analytics project focused on analysing road accident trends in Kerala from 2023 to 2025. The project uses data modelling, DAX, Power Query and interactive visualisations to explore accident patterns and road safety insights.

## Objectives
- Analyse road accident trends across multiple years.
- Examine geographical accident patterns and risk areas.
- Understand accident severity and vehicle-related patterns.
- Present insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Modelling (Star Schema)

## Dashboard Pages

### 1. Executive Overview
High-level overview of road accident statistics and trends.

### 2. Geographic Risk Analysis
Exploration of geographical accident distribution and risk patterns.

### 3. Vehicle & Severity Analysis
Analysis of accident patterns by vehicle category and severity.

### 4. Monsoon & Time Analysis
Exploration of accident trends across time periods and monsoon-related patterns.

### 5. Insights & Recommendations
Summary of analytical findings and road safety recommendations.

## Data Model
The project follows a Star Schema approach with a central accident fact table and supporting dimension tables, including date-related dimensions.

## Project Files
- Power BI report (.pbix)
- Dataset (2023–2025)

## Disclaimer
This project is intended for educational and analytical purposes. Findings depend on the availability, accuracy and completeness of the underlying dataset.
